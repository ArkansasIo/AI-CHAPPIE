# Glossary

- **Brain OS:** High-level task coordination and runtime state, not a biological brain.
- **CMOS-style configuration:** Versioned file-backed settings example, not physical CMOS/NVRAM.
- **E-stop:** Emergency stop initiated by a physical device and independent safety path.
- **STO:** Safe Torque Off function provided by compatible motor drives and safety circuits.
- **MCU:** Microcontroller unit performing a bounded local control or acquisition task.
- **Fail closed:** Missing or invalid evidence results in denial/safe state.
- **Lease:** A bounded command validity interval; expired commands are rejected.
- **HIL:** Hardware-in-the-loop testing.
