This chapter develops the *complete* mathematics behind digital logic gates and
connects it to neural networks. It covers:

1. Boolean algebra (the algebra of `{0,1}`)
2. Truth tables, minterms/maxterms, canonical forms
3. Completeness (how few gates can build everything)
4. The *calculus* of logic — differentiation through gates
5. Smooth / differentiable logic (the bridge to neural networks)
6. Universal approximation via NAND

## 1. Boolean algebra

A **Boolean variable** takes values in `B = {0, 1}`. A **Boolean function** is

```
f : B^n -> B^m
```

We mostly consider scalar outputs (`m = 1`). There are `2^(2^n)` distinct
`n`-input Boolean functions — e.g. `2^4 = 16` two-input functions.

### 1.1 The primitive operations (axioms)

```
AND : a ∧ b   (conjunction)     = 1 iff a = b = 1
OR  : a ∨ b   (disjunction)     = 0 iff a = b = 0
NOT : ¬a      (negation)        = 1 - a
```

### 1.2 Huntington's postulates (the algebra as axioms)

For all `a, b, c ∈ B`:

| Law | Form |
|-----|------|
| Commutative | `a ∧ b = b ∧ a`,  `a ∨ b = b ∨ a` |
| Associative | `(a∧b)∧c = a∧(b∧c)`, `(a∨b)∨c = a∨(b∨c)` |
| Distributive | `a∧(b∨c) = (a∧b)∨(a∧c)`, `a∨(b∧c) = (a∨b)∧(a∨c)` |
| Identity | `a ∧ 1 = a`,  `a ∨ 0 = a` |
| Complement | `a ∧ ¬a = 0`,  `a ∨ ¬a = 1` |

### 1.3 Derived identities (the ones you actually use)

```
Idempotent    a ∧ a = a                     a ∨ a = a
Absorption    a ∨ (a∧b) = a                 a ∧ (a∨b) = a
Domination    a ∧ 0 = 0                     a ∨ 1 = 1
Double neg    ¬(¬a) = a
De Morgan     ¬(a ∧ b) = ¬a ∨ ¬b            ¬(a ∨ b) = ¬a ∧ ¬b
Distrib. (XOR) a ⊕ b = (a∧¬b) ∨ (¬a∧b)
```

**De Morgan's laws** are the algebraic basis of converting between AND/OR/NOT
formulas and NAND/NOR-only circuits — critical for hardware and for proving
gate-set completeness (§3).

### 1.4 The key "arithmetic" identities (B `↔` arithmetic mod 2)

```
AND = multiplication      a ∧ b = a · b
XOR = addition mod 2      a ⊕ b = (a + b) mod 2
NOT = 1 - a
OR  = a + b - a·b
```

These are what let a *continuous* neuron approximate logic: with inputs in
`{0,1}`, `AND` is a product, `XOR` is a parity.

## 2. Truth tables and canonical forms

A truth table lists the output for every one of the `2^n` input rows.

### 2.1 Minterms (sum of products, SOP)

A **minterm** `m_k` is the AND of every variable (negated or not) that is 1 on
row `k`:

```
m_k = (x_1^{s_1}) ∧ … ∧ (x_n^{s_n}),  where x^1 = x,  x^0 = ¬x
```

Any function is the **OR of the minterms where it is 1**:

```
f = ∨_{k : f(row_k)=1}  m_k
```

### 2.2 Maxterms (product of sums, POS)

A **maxterm** `M_k` is the OR of every variable that is 0 on row `k`:

```
f = ∧_{k : f(row_k)=0}  M_k
```

### 2.3 Worked example — XOR

| a | b | a⊕b | minterm |
|---|---|-----|---------|
| 0 | 0 | 0 | — |
| 0 | 1 | 1 | `¬a∧b` |
| 1 | 0 | 1 | `a∧¬b` |
| 1 | 1 | 0 | — |

SOP: `a⊕b = (¬a∧b) ∨ (a∧¬b)`.
POS (zeros at rows 00 and 11): `a⊕b = (a∨b) ∧ (¬a∨¬b)`.

### 2.4 Algebraic normal form (ANF / Zhegalkin polynomial)

Expressed over `{AND, XOR}`, every function is a **polynomial mod 2**:

```
f(x) = c_0 ⊕ c_1 x_1 ⊕ … ⊕ c_n x_n ⊕ c_{12} x_1 x_2 ⊕ …   (mod 2)
```

For XOR this is beautifully simple:

```
a ⊕ b = a + b (mod 2)
```

This is the algebraic heart of why XOR is hard for a single linear neuron and
why *two layers* solve it (a product term `x_1 x_2` is a degree-2 monomial).

## 3. Functional completeness (gate sets)

A set of gates is **functionally complete** if every Boolean function can be
built from it.

| Gate set | Complete? | Notes |
|----------|-----------|-------|
| {AND, OR, NOT} | Yes | the classic basis |
| {AND, NOT} | Yes | OR is derivable by De Morgan |
| {OR, NOT} | Yes | AND is derivable |
| {NAND} | **Yes** | single-gate universal |
| {NOR} | **Yes** | single-gate universal |

### 3.1 Why NAND alone is universal

NAND is `¬(a∧b)`. To recover the basis:

```
NOT a  = a NAND a
a AND b = ¬(a NAND b) = (a NAND b) NAND (a NAND b)
a OR b  = (¬a) NAND (¬b) = (a NAND a) NAND (b NAND b)
```

Since `{AND, NOT}` is complete and both are NAND-only, `{NAND}` is complete.
(The same argument works for NOR.) This is why CMOS hardware is built mostly
from NAND/NOR gates — one gate type fabricates everything.

### 3.2 Post's functional completeness theorem (definition)

A Boolean clone is generated by a set `F`. `F` is complete **iff** it is not
contained in any of the five maximal clones (Post's lattice), characterized by:

* preserves `0` (all f with f(0,…,0)=0), preserves `1`,
* is monotone, self-dual, or affine (preserves XOR).

The affine class is *exactly why* `{XOR, AND}` is complete but `{XOR}` alone
(affine) is **not** — XOR can never produce AND because AND is not affine.

## 4. The calculus of logic — differentiation through gates

This is the part that connects logic to learning. We treat the truth value as a
real number and ask for a derivative.

### 4.1 Why "differentiation of logic" is subtle

`{0,1}`-valued gates are **piecewise constant**, so their classical derivative is
0 almost everywhere:

```
d(AND)/da = 0   for a ∉ {0,1} boundaries
```

Gradient descent on hard gates gives **no learning signal**. The solution is to
**relax** each gate to a smooth function and differentiate *that*.

### 4.2 Smooth (soft / differentiable) gates

Replace the step with the logistic function `σ(z) = 1/(1+e^{-z})`.

**Soft AND** (temperature `τ > 0`):

```
AND_τ(a,b) = σ( (a + b - 1.5) / τ )
```

* As `τ → 0`, this → `a ∧ b`.
* Derivative: `∂/∂a = (1/τ)·σ'((a+b-1.5)/τ)`.

**Soft OR**:

```
OR_τ(a,b) = σ( (a + b - 0.5) / τ )
```

**Soft NOT**: `1 − a` (already smooth and exact).

**Soft XOR** — the hard part. Parity is not linearly separable, so a single
sigmoid cannot express it. Two equivalent constructions:

```
XOR_τ(a,b) = OR_τ( AND_τ(a, ¬b), AND_τ(¬a, b) )          (SOP relaxation)
XOR_τ(a,b) = σ( τ⁻¹ (a + b − 2ab) − 0.5 )                 (algebraic relaxation)
```

using `a ⊕ b = (a + b) mod 2` at hard values and `a ⊕ b = a + b − 2ab` at
`{0,1}`.

### 4.3 The chain rule through a gate network

For a composition `gates` with parameters `θ`:

```
∂L/∂θ = Σ_gates  (∂L/∂out) · (∂out/∂gate) · (∂gate/∂θ)
```

Because every soft gate is a composition of `+`, `−`, `×`, and `σ`, the entire
backward pass reduces to the chain rule + the activation derivative
`σ'(z) = σ(z)(1−σ(z))` from Chapter 3. **A logic circuit is just a neural
network with a particular wiring.**

### 4.4 Gradient of the smoothed step (straight-through intuition)

The derivative of `σ(z/τ)` w.r.t. its *input value* is
`(1/τ)σ(1−σ)`, which peaks at the decision boundary and vanishes in the
saturated regions. Practically:

* **small τ** → near-hard gate, sharp but vanishing gradient,
* **large τ** → soft gate, smooth gradient, biased output.

This trade-off is the *temperature* knob, and it is the same idea used in
Gumbel-softmax and straight-through estimators.

### 4.5 Straight-through estimator (STE)

When you must have hard gates in the forward pass but gradients in the backward
pass:

```
forward :  y = step(z)              (hard 0/1)
backward:  ∂y/∂z ≈ σ'(z)  (or 1)    (pretend it was smooth)
```

STE makes a hard logic network trainable. It is biased (not the true gradient)
but works surprisingly well and is standard in binary neural networks (BNNs).

## 5. Learning gates with a neuron — the geometry

A single neuron `σ(w·x + b)` computes a **half-space** decision. It can
therefore represent any **linearly separable** gate and no others.

| Gate | Linearly separable? | One neuron? |
|------|--------------------|-------------|
| AND | Yes | Yes |
| OR | Yes | Yes |
| NAND | Yes | Yes |
| NOR | Yes | Yes |
| NOT | Yes (1 input) | Yes |
| **XOR** | **No** | **No** |
| **XNOR** | **No** | **No** |

### 5.1 Linear-separability proof for XOR

Suppose `w₁a + w₂b + c` is positive iff `a⊕b = 1`. Then rows `(0,1)` and `(1,0)`
are positive and `(0,0)`,`(1,1)` are negative:

```
(0,1):  w₂ + c > 0
(1,0):  w₁ + c > 0
(0,0):  c < 0
(1,1):  w₁ + w₂ + c < 0
```

Adding the last three conditions: `w₁ + w₂ + c = (w₁ + c) + (w₂ + c) − c > 0 − 0 = >0`,
contradicting `w₁+w₂+c < 0`. **No such neuron exists.** ∎

### 5.2 Minimum-depth solution

XOR needs a hidden layer because it is an **order-2** function: its ANF contains
the degree-2 term `ab` (in the `a+b-2ab` form). A network computes degree-2
monomials in its first hidden layer and ORs the two separable halves in the
output layer — exactly the two-layer construct in `nn/gates.py`.

## 6. Gate logic ↔ neural network dictionary

| Logic | Neural network |
|-------|----------------|
| Input bit | Input feature in `{0,1}` |
| Wire | Identity connection (weight 1) |
| AND gate | Neuron with weights `(1,1)`, bias `−1.5`, step |
| OR gate | Neuron with weights `(1,1)`, bias `−0.5`, step |
| NOT gate | Weight `−1`, bias `0.5`, step |
| NAND (universal) | Weights `(−1,−1)`, bias `1.5` |
| Circuit depth | Number of layers |
| Circuit size | Number of neurons |
| Gate set | Activation function |
| Hard gate | Step activation |
| Soft gate | Sigmoid with temperature `τ` |

**NAND is universal** (§3.1) and **a NAND is a single neuron**, so: *a network of
single neurons of one type can compute every Boolean function.* Together with
§5 this yields the discrete special case of **universal approximation**.

## 7. Summary of the mathematics

```
Algebra    : Huntington postulates, De Morgan, ANF over GF(2)
Combinatorics: 2^(2^n) functions; minterm/maxterm canonical forms
Completeness: {NAND}, {NOR} are singletons that generate all of B
Geometry   : a neuron = half-space; only separable gates in one layer
Calculus   : logic is 0-a.e.; relax with σ(z/τ); chain rule over the circuit
Learning   : soft gates → gradients; STE → trainable hard gates
Universality: NAND is a neuron and NAND is complete  ⇒  nets compute logic;
              linear + nonlinear layers  ⇒  universal function approximation
```
