# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the repository maintainers through GitHub's private vulnerability reporting feature, if enabled. Do not publish credentials, exploit details, or personal information in a public issue.

## Scope

Security-relevant areas include configuration parsing, command authorization, memory/database handling, dependency management, and any future hardware adapter.

## Robot safety

AI-CHAPPIE is a research scaffold and simulator, not a certified safety controller. Do not connect it directly to physical actuators. Report unsafe command handling or bypasses of confirmation/interlock behavior as security issues.
