# Contributing

Thanks for helping improve AI-CHAPPIE.

## Development setup

- Python 3.10+ and pip
- NumPy (installed through `requirements.txt`)
- CMake 3.16+ and a C++17 compiler for the C++ runtime

## Before opening a pull request

Run the checks relevant to your change:

```sh
python -m pip install -r requirements.txt
python -m tests.test_math
python -m pytest -q tests/test_autograd.py tests/test_gates.py
cmake -S ChappieClone -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Keep changes focused, document public APIs, and add regression tests for bug fixes. Never commit credentials, personal data, local databases generated by tests, or build output.

## Robot safety policy

This repository's runtime is a simulator. Changes must preserve safe defaults and must not describe the software as a certified safety controller. Physical-device integrations require independent hardware safety mechanisms and documented verification.
